# Masari 🚕

**Masari** is a transportation application focused on making mobility information and services easier to access.

## 📋 Overview

This repository contains the Masari transportation app, including project documentation, data, experimentation, testing scripts, and starter resources.

## 🛠️ Technology Stack

- **Python** — 81.7%
- **HTML** — 15.9%
- **TypeScript** — 2.4%

## 📂 Repository Structure

- `Tunisia_Mobility_Documentation_Package.zip` — downloadable mobility documentation package
- `Tunisia_Mobility_Project_Starter` — starter project resources
- `data` — project data
- `gemini` — Gemini-related implementation or resources
- `test scripts` — scripts used for testing and experimentation

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- `pip`
- A modern web browser

### Installation

```bash
git clone https://github.com/chedi9/Masari.git
cd Masari
```

Install dependencies when available:

```bash
pip install -r requirements.txt
```

Run the application using the instructions provided in the relevant project directory.

## 🧪 Testing

Testing utilities and experimental scripts are available in the `test scripts` directory.

```bash
python "test scripts/<script-name>.py"
```
