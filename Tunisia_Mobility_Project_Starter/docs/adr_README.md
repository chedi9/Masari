# Architecture Decision Records (ADRs)

Store one numbered ADR per consequential technical choice. Use `0001-short-title.md` naming.

Each ADR must include: status (Proposed/Accepted/Rejected/Superseded), context, options considered, trade-offs, cost/zero-spend impact, decision, consequences, evidence, owner approval, date, and superseded ADR (if any).

An AI may prepare a recommendation, but must not mark it Accepted without explicit product-owner approval.
