# Research and Evidence

Store source audits, dataset profiles, provider comparisons, field-test notes and other evidence here.

Every research artifact should record: author/agent, date accessed, source and URL, license/terms, geographic and mode coverage, update date, methodology, findings, limitations, and whether the evidence supports a product/technical recommendation.

Do not place unverified transport facts into production data.
